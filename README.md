# 菜籃算盤 (Market Veggie Calc) - PWA

專為台灣菜市場買菜與超市採購設計的即時換算、跨通路比價與歷史記帳 PWA 應用。

## ✨ 特色功能

1. **2x2 雙列直覺換算器**：
   - 「單價、重量、總價」任填兩項，自動秒解第三項。
   - 單價與重量單位 1:1 即時連動（支援 **台斤**、**公克**、**公斤**）。
   - 支援「顆數」選填，自動試算單顆平均價與平均單顆重量。
2. **三核心通路設定**：
   - **果菜批發**（預設首選，預設單位：台斤）
   - **一般傳統市場**（預設單位：台斤）
   - **賣場/超市**：內建下拉快捷（萬家福、美聯社、喜互惠、全聯、樂家康、其他，預設單位：公克）。
3. **即時跨通路比價矩陣**：
   - 輸入當前單價時，自動比對該品項在各通路最近一次的歷史行情。
   - 即時計算價差與漲跌趴數（如：省 .0 (-10%) 或 貴 .0 (+15%)）。
4. **歷次價格庫 (Journal)**：
   - 搜尋關鍵字即時過濾、按通路分類篩選。
   - 單筆修改、刪除、清空所有紀錄，以及匯出、匯入 JSON 備份。
   - 所有資料保存於手機本地端 (LocalStorage)，離線亦可使用。建議定期匯出備份；清除瀏覽器網站資料會移除紀錄。匯入備份會在確認後取代目前的全部紀錄。
5. **PWA 手機安裝支援**：
   - 具備專屬小精靈蔬果圖示、啟動 Splash Screen 開屏畫面。
   - 支援 iPhone (Safari) 與 Android (Chrome)「加入主畫面」，享有如同原生 App 的全螢幕沈浸式體驗。

---

## 📱 如何在手機上「加入主畫面」

### iPhone (iOS Safari)
1. 在手機 Safari 瀏覽器中打開本應用網址。
2. 點擊螢幕下方中間的「**分享**」按鈕（帶有往上箭頭的方形圖示）。
3. 往下滑動並選擇「**加入主畫面**」（Add to Home Screen）。
4. 確認名稱為「菜籃算盤」並點選右上角「新增」。
5. 回到手機桌面，點擊專屬小精靈圖示即可全螢幕開啟！

### Android (Chrome)
1. 在 Chrome 瀏覽器中打開本應用網址。
2. 點擊右上角「**⋮**」選單。
3. 選擇「**加到主畫面**」或「**安裝應用程式**」。
4. 點擊「安裝」，完成後即可從桌面開啟。

## 💻 本地端快速啟動預覽

在專案資料夾下執行：
```bash
python -m http.server 8080
```
接著用瀏覽器訪問 http://localhost:8080 即可進行測試。
